# Identity Lifecycle Automation
Status: In Progress — planned demonstration, to be built and tested.
## Objective
Demonstrate how organizations manage employee access efficiently through identity lifecycle automation.
### Skills Learned
- Identity lifecycle management — onboarding, transfers, offboarding
- Group membership based on job roles
- PowerShell automation for identity administration
- Access revocation verification
### Tools Used
- Microsoft Entra ID
- PowerShell
- Microsoft Graph API
## Steps
1. Create a test employee onboarding workflow
2. Assign group memberships based on job roles
3. Automate account updates using PowerShell
4. Simulate employee offboarding
5. Verify that access is revoked appropriately
Evidence to be added: Scripts, sample input data, test results, and documentation.
